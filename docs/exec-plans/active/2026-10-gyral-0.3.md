# Exec plan: the UI on Gyral 0.3

Started 2026-10-07. Beads epic `sabacc-x56` ("Move the UI from Lit to Gyral 0.3 (both
views)").

## Goal

Rewrite the UI layer (`src/components/`, and the 3D view's shell and name plates) as
[Gyral](https://gyral.dev) 0.3 Model-View-Intent components, and drop Lit. Sabacc becomes a
real app that tests Gyral 0.3, the release that replaces Lit with Gyral's own view layer.

Out of scope, unchanged: `src/domain`, `src/protocol`, `src/server`, both stores
(`createStore`, `createRemoteStore`), `src/presentation` and the Three.js `Stage`/`Board`.

## Done when

- No `lit` or `@lit-labs/*` import anywhere; both packages are gone from `package.json`.
- Every element in `src/components/` and `<sabacc-3d>` is a Gyral `define()` component;
  views name intents (`data-intent`), never closures; reducers are pure.
- `npm run check` is green, with model tests (`@gyral/testing`) next to the browser
  tests, and every `npm run drive` path (classic, 3D, shift, multiplayer) runs with no
  console errors and screenshots that match today's.
- Bundle sizes measured against the baseline below and recorded in `docs/FRONTEND.md`.
- `@gyral/*` come from npm at exactly `0.3.0`; `vendor/gyral/` is deleted.

## Steps (beads `sabacc-x56.1` … `.11`)

1. **Vendor 0.3.0** (`vendor/gyral/0.3.0`): core, time, http, testing, devtools, with
   `SOURCE.json` and `SHA256SUMS`. No install yet.
2. **Vite 7 → 8.** `@gyral/core`'s template compiler needs Vite 8 (Rolldown). Check the
   two-page build input, the chunk-size setting, the dev proxy for `/api` and `/ws`,
   Vitest browser mode, and the drive script's `preview()`. Gate: check and drive green;
   sizes recorded (Rolldown may move them on its own, before any Gyral code).
3. **Install and wire.** `npm install` the vendored tarballs, with `overrides` pinning
   `@gyral/core` to `file:vendor/gyral/0.3.0/gyral-core-0.3.0.tgz` (the other packages
   depend on core `0.3.0`, which isn't on npm yet). Spread `gyralVitePreset()` into the
   Vite and Vitest configs. `lint:arch`: `@gyral/*` allowed in `components` and `scene`,
   never in `domain`, `protocol`, `state` or `server`. Add ESLint with only Gyral's
   recommended config (`@gyral/core/eslint`) over `src/components` and `src/scene`, as
   `npm run lint:templates` inside `npm run check`, next to `lint:arch`. The agent reads the
   `gyral` skill from the local checkout. Gate: build and both lints green with no Gyral
   component yet.
4. **Store bridge.** A streaming driver (`table`) that emits `TableChanged` whenever the
   store's `game`, `last`, `log`, `notice` or `room` signals change, plus a `dispatch`
   command that calls `store.dispatch`. Works for both stores. Fake driver for tests.
5. **Spike: `<sabacc-controls>`** (checkpoint). Shared by both views and the most
   closure-heavy element: bet amount with a `value=` binding, Lock/Trade picking, outputs
   to the parent instead of `CustomEvent`s. Measure the bundle with Lit and Gyral side by
   side. **Checkpoint:** the owner reviews the first real component, the bundle numbers
   and anything learned about Gyral before the rest is converted (the migration is going
   ahead; this is where the approach can still change cheaply).
6. **Card, log, seat.** `sabacc-card`'s `svg` templates become inline `<svg>` in `html`;
   the log uses `each` with pure rows; the seat's Lock/Trade become outputs.
7. **Room panel.** `@gyral/http` for `POST /api/rooms`, a clipboard driver, the countdown
   from `@gyral/time` `periodic` (only while a clock runs).
8. **Classic table and playback.** `BeatPlayer`'s timer becomes model state plus
   `@gyral/time` `delay` commands, tested with virtual time. Browser tests move from
   `updateComplete` to `settled()`.
9. **3D shell and plates.** `<sabacc-3d>` mounts the `Stage` through a hook
   (`defineHook`); the name plates (Lit `render()` into CSS2D divs today) become a small
   component or a hook. The scene itself stays imperative.
10. **Remove Lit.** Drop `lit` and `@lit-labs/signals`; the stores use `signal-polyfill`
    (what `@lit-labs/signals` re-exports) directly. Remove `experimentalDecorators` if
    nothing else needs it. Update ARCHITECTURE, FRONTEND, AGENTS (skills), QUALITY_SCORE.
11. **npm 0.3.0** (deferred to 2026-10-10). Install from the registry, exact versions;
    the registry tarballs' SHA-256 must match `vendor/gyral/0.3.0/SHA256SUMS`, or find out
    why before switching. Remove the overrides and `vendor/gyral/`.

## Risks

- **Two view layers at once** during steps 5–9: Lit and Gyral both ship until step 10.
  Fine on a branch; measure, don't guess.
- **Vite 8** is a bundler change (Rolldown) by itself; keep it a separate, green step.
- **Game state isn't JSON** (`Option`, `Data` values). Gyral wants JSON-serializable state
  for hydration; this UI is client-only, so `TableChanged` may carry the game as is. Don't
  server-render game components.
- **0.x churn:** 0.1, 0.2 and 0.3 shipped within three days. Pin exact versions.
