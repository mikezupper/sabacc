# Exec plan: 3D table view

Started and completed 2026-10-04. Beads epic `sabacc-afk` ("3D table view (Three.js)
sharing the engine and store").

## Goal

A second way to play: a Three.js table at `3d.html`, beside the classic Lit page, that
shares the engine, the store, beat playback, the wording and the controls. Only the
drawing differs.

## Done when

- `3d.html` plays whole hands: deal, bet, pick/lock/trade, shifts, call and reveal,
  with animated beats, on desktop and phone, in both colour schemes.
- The classic page behaves as before and doesn't load Three.js.
- `npm run check` is green; `npm run drive` paths `3d` and `3d-shift` run with no
  console errors and the screenshots have been reviewed.

## Steps (beads `sabacc-afk.1` … `.6`)

1. `src/presentation/`: wording, prompt and a framework-free `BeatPlayer`.
2. `<sabacc-controls>` shared by both views (with a card picker for 3D).
3. Layer rules: `presentation` and `scene` in `lint:arch` and ARCHITECTURE.md.
4. The scene: table, cards keyed by id, chips, deck, dice, dealer button, turn ring,
   plates, beat effects, picking.
5. `3d.html`, `entry-3d.ts`, `<sabacc-3d>` HUD, WebGL fallback, Vite multi-page build.
6. Tests, drive paths, docs.

## Decision log

- 2026-10-04: **Three.js**, not Babylon, React Three Fiber or a native engine: plain
  TypeScript in the existing Vite build, and the Effect engine stays the only rules
  implementation. Owner asked for shared code; agent chose the library.
- 2026-10-04: **Separate page** (`3d.html`) rather than a toggle, so the classic page
  never ships Three.js. Agent.
- 2026-10-04: **Snapshot-driven scene.** Objects ease towards placements computed from
  each snapshot; beats only add effects. Same rule as the 2D playback: no game state
  in timers or scene objects. Agent.
- 2026-10-04: **Procedural textures**, no image or model assets. Agent.
- 2026-10-04: **Saved table is shared** by both pages (same storage key). Agent.
- 2026-10-04: **HTML name plates** (CSS2DRenderer) for crisp text that uses the page's
  fonts. Agent.

## Progress log

- 2026-10-04: All steps done. Bug found while building and covered by a regression
  test: a card object reused for a shift kept its old id and was discarded on the
  next snapshot.
