# Sebaac Game

## Prereqs

Use Node 20 

## Install

`npm install`

## Development

`npm run watch` or `npm run dev`

## Build 

The src/main.jsx file will be 'built' using esbuild and store the generator file under the js folder

`npm run build`

## Package up
`npm run package`

## Preview

using VS Code and Live Server plugin, open the index.html file "Using Live Server"
